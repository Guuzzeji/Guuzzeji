### 🧃 About me

Hey, I'm **Gabe**, a.k.a. **Guuzzeji** (pronounced *"Goose-za-jee"* 🪿). Self-taught dev, currently located somewhere in The Matrix 💾.

I build **weird and funny things**. Sometimes they're useful. Sometimes I statically recompile a 2006 Burger King stealth game so it runs natively on PC. No regrets.

- 🛠️ Mostly writing **TypeScript / JavaScript**, **Go**, and **Python**. I dabble in **C**, **Svelte**, and **Godot**
- 🤖 Lately: AI agent tooling, recomps, and job-hunting robots
- 🎮 Game jams whenever I can sneak one in
- 📝 I write random notes over at the [BACKR00M](https://backr00m.xyz/). Watch where you step
